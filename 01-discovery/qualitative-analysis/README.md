## Как пользоваться

- Исследования: полные тематические тексты здесь, включая ограничения, цитаты и альтернативы, уже включённые автором канона.
- Решения: [реестр точных фрагментов](../../04-requirements/canonical-decisions-register.md).
- Требования: [карта изменений](../../04-requirements/canonical-sync-20261120.md) и актуальная Google Sheets Matrix; не заменять требования копией всего анализа.
- Гипотезы: исходные H-01–H-05 и другие гипотезы остаются со своими исходными статусами. Никаких автоматических повышений статуса.
- Архивы: прежние промежуточные решения и прогресс-трекеры сохранены внутри q08-q70; финальные статусы читать по последующим разделам.

## Неурегулированные коллизии источника

1. Исторические ENG-03 параметры против открытого engineering layer RF-80.
2. Остаточные формулировки Q101–Q120 о незакрытой QA Q71–Q80 / неопределённом наличии Views против финального Q71–Q80.
3. Режим «По ссылке» не тождественен Friends-only; отмена D-14 не выводится из нового словаря.
4. При переносе API встречается оборванный параграф перед приложением (начинается «дет выглядеть»); он сохранён как повреждение источника, не восстановлен предположением.
