# portfolio — собранные материалы

Материалы сгруппированы по происхождению для проверки. Это не утверждённая структура будущей документации и не утверждённая спецификация продукта.

- `01-discovery/` — локальный черновик рамки Discovery и Project Scope.
- `02-ithub-main-site/` — сохранённые материалы и контрольные точки исследования основного сайта `ithub.ru` и его доски FigJam. Эти файлы не являются отдельным исследованием `spb.ithub.ru`.
- `03-behance-reference/` — исследование Behance и проектные предположения о самостоятельной платформе; переносить их в требования portfolio без сверки нельзя.
- `04-requirements/` — найденная исходная матрица и её отдельная рабочая копия.
- `05-training-frontend/` — рабочая песочница Discovery с документами, гипотезами, сущностями, матрицей и отчётом; инструкции по локальному запуску и Vercel находятся в её README.
- `GITFLOW.md` — ветки и порядок выпуска песочницы.
- `AUDIT.md` — реестр источников, доступности, расхождений и материалов для ручного восстановления.

Исследовательские материалы скопированы из локального зеркала проекта, матрица — из папки «Загрузки»; исходные файлы оставлены на месте. Внешние сайты, FigJam и GitHub записаны ссылками в реестре, без создания локальных копий их содержимого.
