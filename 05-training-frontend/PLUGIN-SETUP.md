# Portfolio Discovery в ChatGPT

Личный приватный [Plugin «Portfolio Discovery»](https://chatgpt.com/plugins/plugins_6ae8be7eaf548191af8464bcb7948351) содержит правила работы с проектом. Он подключается к опубликованному MCP-серверу `https://portfolio-discovery.vercel.app/mcp` через OAuth 2.1 с PKCE. На личном аккаунте ChatGPT создание новых GPT недоступно, поэтому используется Plugin.

## Подключение

1. Убедитесь, что на сайте в разделе **GPT и облако** отображается «Облако подключено».
2. В личном Plugin добавьте custom MCP server с URL `https://portfolio-discovery.vercel.app/mcp`. Выберите OAuth и регистрацию клиента через Client ID Metadata Document (CIMD). Сервер публикует OAuth metadata и protected resource metadata по стандартным `/.well-known/` адресам.
3. При первом вызове инструмента ChatGPT откроет страницу подтверждения на `portfolio-discovery.vercel.app`. Введите там тот же ключ Discovery, который установлен в Vercel. Не отправляйте ключ в чат или код.
4. В чате с Plugin проверьте чтение контекста командой «Покажи актуальный Project Scope», затем отправку тестового предложения. Оно должно появиться на сайте во входящих и попасть в материалы только после нажатия **Добавить в Discovery**.

## Модель обмена

- `get_discovery_context` читает текущую облачную копию через `/api/gpt`.
- `submit_discovery_proposal` отправляет новую гипотезу, наблюдение, требование, решение, задачу, сущность или документ во входящие.
- OAuth-токены дают ограниченный доступ к этим инструментам. Ключ Discovery остаётся серверным секретом; пользователь вводит его только на странице подтверждения своего сайта.
- Доступ работает в чате, где выбран личный Plugin. ChatGPT не передаёт этому сайту историю всех обычных чатов автоматически.

Старая [схема GPT Actions](gpt-action.yaml) сохранена как технический архив; личные аккаунты больше не могут создать новый GPT с Actions.
